# Udita Homestay Blog Workflow

The public blog is served from `blogs.html`.

## Adding a new article

1. Add a new article card inside the `.blog-grid` section of `blogs.html`.
2. Use an image already in `assets/images/` where possible so the journal stays visually consistent with the main site.
3. Keep the existing card structure and classes so typography, spacing and responsive behavior remain consistent.
4. For a fully published article, replace the `Coming soon` text with a `Read article` link to the article page or an authoritative external source.
5. Update the date, category and reading time in the card metadata.
6. Keep factual travel information current and verify changing details such as timings, access rules and event dates before publishing.

## Design rules

- Keep the existing cream, green, brown and muted-gold palette.
- Prefer high-quality landscape photography with descriptive `alt` text.
- Avoid changing the existing home page sections, booking links, contact details or social buttons when publishing a blog post.
- Keep titles concise and editorial rather than promotional.
- Use authoritative sources for historical or heritage claims.
